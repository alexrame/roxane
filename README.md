# roxane-rame-mattsson.org

Single-page birth announcement for Roxane, served by GitHub Pages.

- Edit the `BABY = {...}` block at the top of the `<script>` in `index.html`.
- Drop a photo named `photo.jpg` next to `index.html` (4:3 works best; ~1200px wide is plenty).
- `CNAME` tells GitHub Pages to serve this repo at `roxane-rame-mattsson.org`.
- DNS (Hover, roxane-rame-mattsson.org): A records -> GitHub Pages IPs, `www` CNAME -> alexrame.github.io
